# Node 16.14 Compatibility Plan

## Goals

- Lower the core package runtime floor from Node.js 18 to Node.js 16.14 without redesigning BlueNote behavior.
- Keep generated `dist/` output ignored by git while preserving package builds and pack artifacts.
- Document the core repository using the same docs top-level organization as `bluenote-term`.

## Tasks

1. Update runtime metadata, CI, dependency versions, and docs to state Node.js 16.14 compatibility.
2. Keep source imports and package exports compatible with Node.js 16.14 ESM behavior.
3. Ensure child-process tests that verify queue behavior execute freshly built package output by making `npm test` rebuild before Vitest, while leaving generated `dist/` untracked.
4. Align repository hygiene with BlueNote terminal conventions: exact npm saves through `.npmrc`, ignored build/cache/local state, and docs under `docs/architecture`, `docs/phases`, `docs/plans`, `docs/product`, and `docs/workflow`.
5. Run `npm run check` before merge.
